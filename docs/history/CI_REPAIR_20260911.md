# 公開CIの修復（2026-09-11）

対象は公開リポジトリの検証経路。エミュレーター実装、性能値、固定targetの契約を変更しない。

## 原因と修正

[失敗run 34602247766](https://github.com/FuyukiYoneyama/picocalc_emu/actions/runs/34602247766)
ではportableのrelease検査と、target-schema／Python testsが失敗していた。

- `jsonschema`未導入: `requirements-dev.txt`を追加し、該当CI jobで導入する。
- 証拠を禁止firmwareと誤分類: 生UART 17個、flash export 1個、固定PicoTetris BIN 1個を
  `firmware-validation/retained-binaries.json`にpath・用途・hashで個別登録。
  既存evidenceは変更も削除もしない。未登録binary、改変、欠損、不正manifest、
  evidence外path、公式sampleは引き続き拒否する。8件の回帰テストを追加した。
- 公開後も残っていたprivate checkout設定: 2件のfirmware jobを公開HTTPS取得へ変更。
  秘密鍵を不要にし、固定commit照合・build・firmware回帰は維持した。
- 直近の実測原本について、既存`SHA256SUMS`全件照合をCIに追加。

`picoem-picocalc`は公開commit `32d27ff`の
[CIが成功済み](https://github.com/FuyukiYoneyama/picoem-picocalc/actions/runs/34597874793)。
今回の問題に対応するためのbackend変更は不要だった。
