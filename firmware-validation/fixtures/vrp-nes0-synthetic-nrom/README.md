# VRP-NES-0 synthetic NROM fixture

This directory contains the repository-owned NES-class input for the
Validated Realtime Preview qualification baseline.  It is an original,
deterministic test image; it is not a dump of a commercial cartridge and it
contains no third-party game data.

## Generation

From the `picocalc_emu` repository root:

```sh
python3 tools/generate_vrp_nes0_nrom.py \
  firmware-validation/fixtures/vrp-nes0-synthetic-nrom/TEST.NES
```

The generator uses only the Python standard library and writes the same
41,488-byte image on every run.  The image is an iNES NROM-256 (mapper 0)
with a 512-byte deterministic trainer, 32 KiB PRG-ROM, and 8 KiB CHR-ROM.
The trainer intentionally sets the image size to the NESco Mapper-0 flash
threshold, so the M-NESCO oracle observes the flash/XIP-backed SD path.

The reset program is a short 6502 loop which configures the PPU/APU, writes a
palette and nametable prefix, enables background rendering, and loops at a
fixed address.  PRG vectors point to `$8000`; CHR bytes are generated by a
fixed arithmetic pattern.  No ROM bytes are copied from an external project.

`TEST.NES` is also copied into `sd/TEST.NES` by the fixture preparation
procedure.  The SD tree contains no other files.
