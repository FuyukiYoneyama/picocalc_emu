# Security

This project is an emulator and development harness. It is provided without
any security-response SLA or private disclosure channel. Do not include
credentials, access tokens, private keys, probe serials, or private hardware
logs in an issue or pull request.

For a suspected vulnerability, open a minimal public issue only when the
details are safe to disclose. Otherwise, keep the report private with the
repository owner and do not attach secrets. Users who need a guaranteed
response should maintain a private fork and apply their own security policy.
